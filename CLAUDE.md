# Working on this project

## Writing

Use standard technical English wherever possible. Keep responses concise:
direct, unstylized sentences.

This applies to everything written here, not just chat: code comments, commit
messages, README and other docs, and user-facing copy in the app. State what
something does and why. Do not use literary or figurative phrasing, metaphor,
or rhetorical constructions.

Existing comments in this repo do not all follow this rule yet. When editing a
file, bring the parts you touch into line rather than matching the older style.

## Commits

Do not commit or push between 09:00 and 17:30 Eastern Time, Monday to Friday.
Check the clock before committing. Inside those hours, finish the work, leave
it uncommitted, and say so — then commit and push outside them.

One change, one commit. Do not bundle unrelated changes into a single commit.
Where a piece of work contains several independent changes, split it into a
commit per change.
